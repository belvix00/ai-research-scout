AI Research Scout — Research Questions Inbox

Purpose: durable inbox for questions generated by daily/weekly scout runs. Questions should be mechanism-first and should not be forced through any single prior hypothesis.

Triage labels

  • open — worth tracking but not yet actionable
  • candidate — could become an experiment/blog section
  • experiment — has a concrete minimal test
  • answered — resolved by evidence, implementation, or decision
  • killed — not worth pursuing now

Candidate experiments

  • experiment Rollout-lifecycle diagnostics for reasoning/tool RL. In a fixed toy math/tool environment, perturb strategy priors, generation diversity, verifier noise, per-turn information-gain shaping, prompt-space perturbations, stopping/control, replay age, and runtime path one at a time. Measure trajectory distribution $$q(\tau)$$, zero-advantage rate, verifier errors, tool success, and gradient cosine against a wide/clean reference sampler. See [[2026-05-07-rollout-lifecycle-gradient]] and [[2026-05-09#1. Compare agentic RL lifecycle interventions under a fixed toy environment]].
  • experiment Shared MoE expert pools and route masks as causal capacity probes. Train tiny layer-local and globally shared expert-pool MoEs on synthetic domain/rare-feature factors. Measure usage matrices $$U_{\ell,g}$$, router entropy, $$I(G;F\mid\ell)$$, expert ablation losses $$\Delta_{g,F}$$, cross-layer gradient cosine, rare-feature retention, and overflow/drop rate. See [[2026-05-09-moe-expert-allocation]].
  • experiment Cost-normalized long-context access benchmark. Compare dense retrieval, compact concept signatures/summaries, raw corpus grep/read/script access, explicit context operations, and full-context prompting on a local corpus with exact constraints, sparse clues, and distractors under equal token/time/tool/KV budgets.
  • experiment Mechanism-preserving inference/runtime harness. Run the same small model/task under baseline and one optimized path: low-bit weights, low-bit/adaptive KV, speculative decoding, cache handoff, expert prefetch, or different serving backend. Measure output agreement, logit/activation drift where possible, attention entropy, rare-feature accuracy, rollout reproducibility, verifier disagreement, latency, memory, and bandwidth.
  • experiment Temporary-lossy pretraining recovery geometry. Train a tiny LM with an early lossy-token or compressed-attention phase, then restore exact AR/full-attention training. Measure coarse-vs-exact gradient cosine, rare-token/order-sensitive/long-context recovery lag $$\mathrm{Lag}_F$$, per-slice gradient-energy retention $$R_F$$, and matched-FLOP speedup. See [[2026-05-11-temporary-lossy-pretraining]] and [[2026-05-11#1. Test temporary-lossy pretraining on a tiny language model]].
  • experiment Speech factor survival probe. Use WavLM/ECAPA/codec states or a small speech-native stack to probe speaker, script/language/accent, phoneme/content, prosody, entity identity, and context metadata. Test correct vs shuffled metadata, gradient-reversal nuisance removal, entity-dense synthetic curricula, EHR/WER regression, and real-recording sanity checks.
  • experiment Sparse branch-selection audit for reasoning post-training. On a fixed math/code rollout set, compare pairwise DPO, graph/listwise preference targets, entropy-gated contrastive correction, and winner SFT. Measure prefix-local KL concentration, promoted-token base rank, entropy/value-gap overlap, candidate-simplex movement, diversity of correct strategies, and activation-vs-logit locality. See [[2026-05-13-sparse-branch-rl]].
  • experiment Cheap hallucination/uncertainty probe overlap map. On one small factual QA set, log first-content-token entropy, ordinary logprob, middle-layer attention divergence/KL, semantic self-consistency, answer type, and correctness. Cluster failures by which signal catches them.
  • experiment Visual grounding persistence / attention dilution demo. Create simple images with late-needed details; compare short answer, long answer, and long answer with visual refresh/memory summary. Measure detail accuracy vs generation length and attention-to-image fraction if available.
  • experiment Text-conditioned visual SSL nameability probe. Create/reuse synthetic images with nameable/captioned and non-nameable/uncaptioned factors. Compare visual SSL, text-conditioned SSL, end-to-end tokenizer, and caption-randomized controls with linear probes and local-factor corruption metrics.
