Why Vision-Language Models Stop Looking: Attention Dilution from First Principles

Why this concept appeared in the scout

Today's scout surfaced a paper on Persistent Visual Memory for large vision-language models. The interesting phrase was visual signal dilution: as a multimodal model generates more and more text, its attention to the original image can decay. This is not just a vague "the model forgot the image" story. There is a clean mathematical reason this can happen.

The opportunity is useful because it turns a messy multimodal failure into a simple mechanism:

If visual tokens and text tokens compete inside one softmax attention pool, then adding more text tokens can reduce the probability mass available to visual tokens.

Let's derive that from the beginning.

Start from the simplest possible problem

Imagine you are answering a question about an image.

The image contains one important fact:

  • The mug is red.

The conversation also contains many text tokens:

  • user question
  • previous answer tokens
  • chain-of-thought-like intermediate text
  • tool messages
  • captions
  • formatting tokens

At the start, the model only has a few text tokens, so the image tokens are easy to consult. Later, after generating a long answer, the model has hundreds or thousands of text tokens in its context. The red mug fact is still present in the image tokens, but now it competes with a much larger textual history.

The central question:

When the model decides what to generate next, how much of its attention goes to the image versus its own text history?

To answer that, we need to invent attention.

Inventing attention from first principles

Suppose we have a current hidden state q, called a query. It represents what the model is currently looking for.

Every previous token has a key k_i, representing what information that token can offer.

A natural way to measure relevance is a dot product:

$$\mathrm{score}_i = q^\top k_i$$

If score_i is large, token i seems relevant. If it is small, token i seems irrelevant.

But raw scores are not probabilities. We want weights that are:

  1. non-negative
  2. sum to 1
  3. larger when the score is larger

The standard answer is softmax:

$$a_i = \frac{\exp(\mathrm{score}_i)}{\sum_j \exp(\mathrm{score}_j)}$$

Then the model forms a weighted mixture of value vectors v_i:

$$\mathrm{output} = \sum_i a_i v_i$$

So attention is just:

compare current query to all keys, normalize those comparisons into probabilities, and average the corresponding values.

Where dilution enters

Now split the context into two groups:

  • image tokens: I
  • text tokens: T

The total attention assigned to image tokens is:

$$A_{\text{image}} = \frac{\sum_{i \in I} \exp(\mathrm{score}_i)}{\sum_{i \in I} \exp(\mathrm{score}_i) + \sum_{j \in T} \exp(\mathrm{score}_j)}$$

Define:

$$S_{\text{image}} = \sum_{i \in I} \exp(\mathrm{score}_i)$$
$$S_{\text{text}} = \sum_{j \in T} \exp(\mathrm{score}_j)$$

Then:

$$A_{\text{image}} = \frac{S_{\text{image}}}{S_{\text{image}} + S_{\text{text}}}$$

This equation is the whole mechanism.

If S_text grows while S_image stays roughly fixed, then A_image shrinks.

For example, suppose the image contributes total softmax mass score:

$$S_{\text{image}} = 10$$

Early in the answer, text contributes:

$$S_{\text{text}} = 10$$

Then:

$$A_{\text{image}} = \frac{10}{10 + 10} = 0.5$$

Half the attention goes to the image.

Later, after a long generation, suppose many text tokens are moderately relevant:

$$S_{\text{text}} = 90$$

Then:

$$A_{\text{image}} = \frac{10}{10 + 90} = 0.1$$

Now only 10% goes to the image.

The model did not delete the image. The image tokens are still there. But the softmax denominator became dominated by text.

This is attention dilution.

The neural network version

In a transformer layer, this happens across many heads and layers.

For one attention head:

$$Q = XW_Q, \quad K = XW_K, \quad V = XW_V$$
$$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V$$

For a generated token at position t, its query attends over previous positions. If the context contains image tokens plus generated text tokens, the softmax is normalized across all allowed positions.

So the visual information must win a competition against:

  • the original prompt
  • previous answer tokens
  • instruction tokens
  • formatting tokens
  • any scratchpad-like text
  • repeated entities introduced by the model itself

The longer the generation, the more competitors exist.

The mathematical bottleneck is not simply sequence length. It is:

$$\frac{\text{visual relevance mass}}{\text{total relevance mass}}$$

If the model generates text that is internally self-consistent, those generated tokens may become highly relevant to future tokens. The model can start attending to its own story more than the image. That is how visual drift can happen.

A simple derivative intuition

The softmax also shapes gradients.

If an image token gets attention weight a_i, then its value vector contributes:

$$a_i v_i$$

When a_i becomes tiny, the image token has little effect on the output. It also receives weaker learning signal through that attention path.

A very rough intuition:

$$\text{small attention weight} \rightarrow \text{small contribution} \rightarrow \text{small correction signal}$$

So dilution is not only an inference-time issue. During training, if long multimodal sequences often bury image tokens under text, the model may not learn robust mechanisms for repeatedly re-accessing visual evidence.

Where the bottleneck appears

The bottleneck appears at the shared attention pool.

The architecture asks one mechanism to do two jobs:

  1. maintain a long textual discourse
  2. preserve access to visual evidence

But these two jobs have different needs.

Text discourse wants rich self-conditioning. The model should remember what it already said.

Visual grounding wants persistent access to the original perceptual facts. The model should keep checking the image.

If both jobs share one softmax competition, text can crowd out vision.

This suggests the fix: give visual information a path that does not vanish just because the text history grows.

Inventing persistent visual memory

From first principles, if the problem is:

$$A_{\text{image}} = \frac{S_{\text{image}}}{S_{\text{image}} + S_{\text{text}}}$$

then possible fixes include:

  1. Increase S_image

- make visual keys more relevant

- add stronger visual retrieval heads

  1. Decrease irrelevant S_text

- compress text history

- remove unneeded generated tokens

  1. Avoid the shared denominator

- give vision a separate pathway

- retrieve visual memory outside standard attention

- periodically refresh visual facts

Persistent visual memory is in the third family. Instead of forcing visual evidence to compete with all text tokens at every step, keep a dedicated visual route available.

A simple conceptual architecture:

normal transformer path: text + image mixed through attention
visual memory path:     direct access to compact visual embeddings
combined output:        normal_output + visual_memory_output

This is similar in spirit to adding a side-channel for information that the main channel tends to lose.

That should sound familiar: many research opportunities are side-channel opportunities.

  • LoRA can be a side-channel for low-rank adaptation.
  • MTP can be a side-channel for richer output gradients.
  • persistent visual memory can be a side-channel for visual evidence.
  • agent memory can be a side-channel outside raw context.

Why this becomes a research opportunity

The opportunity is not merely to say “attention dilution exists.” The opportunity is to build a clean diagnostic.

A good diagnostic should ask:

Does visual grounding degrade as generated text length increases, even when the relevant visual fact remains unchanged?

This is a beautiful small experiment because the causal variable is simple: output length.

You can create images with details like:

  • a red mug next to a blue notebook
  • a tiny number on a sign
  • an object in the top-left corner
  • two similar objects with one distinguishing attribute

Then ask a model to produce long answers where it must recall the detail at the end.

If accuracy drops with answer length, that suggests visual evidence becomes less accessible over generation.

A tiny experiment you can run

Dataset

Create 50 simple images manually or synthetically. Each image has one critical detail.

Example:

Image: a red triangle above a green circle
Question: Write a 300-word story about the scene. At the end, answer: what color was the triangle?
Correct answer: red

Conditions

Run three conditions:

  1. Short answer

- ask directly for the detail

  1. Long answer

- ask for a long explanation, then the detail

  1. Long answer with visual refresh

- insert a compact reminder midway, e.g. “Before final answer, re-inspect the image.”

Metrics

$$\mathrm{accuracy}_{\text{short}}, \quad \mathrm{accuracy}_{\text{long}}, \quad \mathrm{accuracy}_{\text{long+refresh}}$$

If:

$$\mathrm{accuracy}_{\text{short}} > \mathrm{accuracy}_{\text{long}}$$

then visual grounding degrades with generation length.

If:

$$\mathrm{accuracy}_{\text{long+refresh}} > \mathrm{accuracy}_{\text{long}}$$

then some cheap persistent-memory or refresh mechanism may help.

Optional mechanistic probe

If you can access attention maps, measure:

$$\mathrm{visual\_attention\_fraction}_t = \mathrm{attention\_mass\_to\_image\_tokens}_t$$

Plot:

$$\mathrm{visual\_attention\_fraction}_t \; \text{vs.} \; t$$

The expected curve under dilution is downward sloping.

Why this is good for your research taste

This concept has the kind of shape you like:

  1. It starts with a precise mechanism.
  2. The math is simple enough to derive.
  3. The failure can be tested with a tiny experiment.
  4. The result can become a visually clear demo.
  5. It connects architecture, inference behavior, and representation bottlenecks.

It also echoes a broader small-model bottleneck pattern: the model may contain useful information somewhere, but the interface makes access uneven.

For rare tokens, the bottleneck may be gradient flow through tied input/output embeddings.

For images, the bottleneck may be attention mass through a shared softmax denominator.

Different surface. Same deeper question:

Which useful signals get crowded out by the dominant channel?

What to remember

The key equation is:

$$A_{\text{image}} = \frac{S_{\text{image}}}{S_{\text{image}} + S_{\text{text}}}$$

As generated text grows, S_text can grow. If S_image does not grow with it, the image gets a smaller fraction of attention.

That is visual signal dilution.

The research move is to test whether grounding failures are actually state-access failures, then try small fixes:

  • visual refresh prompts
  • compact visual memory summaries
  • separate visual memory paths
  • attention regularization
  • retrieval-style visual side-channels

The broader lesson:

Long-context multimodal intelligence may depend less on having all information in the context, and more on keeping the right information accessible at the right time.
