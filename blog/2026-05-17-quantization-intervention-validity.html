Quantization Survival: When a Model Edit Stops Being the Same Intervention

Why this concept appeared in the scout

The recent scout notes kept circling the same deployment trap from different directions:

  • Forgetting That Sticks argues that unlearning should be validated after the quantization path users actually run, not only in fp16.
  • Widening the Gap shows the adversarial version: outliers can make a model look benign in high precision and then change behavior after quantization.
  • XFP and hardware-aware per-layer PTQ work make quantization less uniform and more targeted, which is good for quality but complicates mechanism claims.
  • The weekly synthesis promoted deployment-path validity for interventions: refusals, unlearning edits, steering vectors, LoRAs, DPO deltas, and rare-skill updates are not fully validated until they survive the shipping representation.

This post is a foundations refresher on that measurement problem. The point is not another quantization tutorial. It is to pin down a sharper question:

If an intervention is a small displacement in parameter, activation, or logit space, when does low-bit deployment preserve its causal effect, erase it, or alias it into a different behavior?

Aman already knows how to fine-tune and quantize models. The useful refresher is the geometry: quantization is a many-to-one map, intervention deltas live relative to bin boundaries, and behavior survival depends on whether the downstream function remains on the same side of the relevant decision margins.

Quantization is a projection, not passive storage

Let a model with parameters $$w\in\mathbb{R}^d$$ implement logits

$$z(x;w)\in\mathbb{R}^{|V|}.$$

A model intervention changes parameters by

$$w' = w + \Delta w.$$

For a refusal edit, unlearning patch, LoRA merge, DPO delta, or small rare-feature fine-tune, much of the causal claim is about the behavioral difference

$$\Delta z(x)=z(x;w+\Delta w)-z(x;w).$$

Deployment inserts a quantization map $$Q$$. The actually shipped models are not $$w$$ and $$w+\Delta w$$, but

$$\widehat{w}=Q(w),\qquad \widehat{w}'=Q(w+\Delta w).$$

So the deployed intervention is

$$\Delta_Q w = Q(w+\Delta w)-Q(w),$$

not $$\Delta w$$. The survival question is therefore

$$\Delta_Q z(x)=z(x;Q(w+\Delta w))-z(x;Q(w))$$

versus the intended high-precision effect $$\Delta z(x)$$.

If $$Q$$ were a small unbiased noise source, we could treat this as ordinary robustness. But quantization is structured and discontinuous. It rounds values into bins, handles outliers specially, estimates scales over groups, and may use calibration data that is unrelated to the intervention target. That makes it a causal transformation of the object being tested.

The scalar bin picture: when an edit vanishes

Start with one scalar parameter. Uniform affine quantization can be idealized as

$$Q_b(w)=b\cdot \mathrm{round}\left(\frac{w}{b}\right),$$

where $$b$$ is the local step size. The quantization error is

$$e(w)=Q_b(w)-w.$$

After an intervention $$\Delta w$$, the deployed delta is

$$\Delta_Q w = Q_b(w+\Delta w)-Q_b(w).$$

This gives a simple local survival ratio:

$$\rho = \frac{|\Delta w|}{b}.$$

If $$\rho\ll 1$$, many updates do not cross a rounding boundary and are erased:

$$Q_b(w+\Delta w)=Q_b(w) \quad\Rightarrow\quad \Delta_Q w=0.$$

If $$\rho\approx 1$$, survival becomes boundary-dependent: two equal-magnitude updates can have different deployed effects depending on where $$w$$ sits inside its bin. If $$\rho\gg 1$$, the update usually survives in magnitude, but not necessarily in direction once group scales, clipping, outlier handling, and nonlinear downstream effects enter.

A useful decomposition is

$$\Delta_Q w = \Delta w + \left[e(w+\Delta w)-e(w)\right].$$

The second term is not just background noise. It is the change in quantization error induced by the edit. For small edits near thresholds, this term can be the same size as the edit or larger.

Group scales make the edit nonlocal

Most useful LLM quantization is not independent scalar rounding with a fixed global bin width. A group of weights is quantized using a scale. In a simplified symmetric form for group $$g$$,

$$s_g = \frac{\max_{i\in g}|w_i|}{q_{\max}}, \qquad Q_i(w)=s_g\cdot \mathrm{clip}\left(\mathrm{round}\left(\frac{w_i}{s_g}\right),-q_{\max},q_{\max}\right).$$

Now an edit to one coordinate can change the group scale:

$$s_g' = s_g(w+\Delta w).$$

The deployed delta for coordinate $$i$$ is

$$\Delta_Q w_i = s_g' r_i' - s_g r_i,$$

where $$r_i$$ and $$r_i'$$ are integer codes. Even if $$r_i'=r_i$$, a changed scale moves all reconstructed values in the group:

$$\Delta_Q w_i = (s_g'-s_g)r_i.$$

This is the basic outlier coupling. If a new or shifted outlier changes $$s_g$$, the bin width for many unrelated coordinates changes. An intervention can therefore be erased in its intended sparse location while inducing small correlated changes elsewhere. Conversely, an adversarial outlier can be constructed so that quantization reassigns effective capacity away from behavior-critical directions.

This is why per-channel floors, sparse outlier separation, and hardware-aware layer policies are mechanism-relevant. They choose which components get small bins, which outliers are isolated, and which layers are allowed to absorb error.

From parameter survival to behavior survival

A parameter delta can survive quantization but still fail behaviorally. The model acts through logits and margins.

For a prompt $$x$$ and target behavior contrast between token/response classes $$a$$ and $$b$$, define the high-precision margin

$$m(x;w)=z_a(x;w)-z_b(x;w).$$

An intervention is intended to shift this margin by

$$\Delta m(x)=m(x;w+\Delta w)-m(x;w).$$

The deployed shift is

$$\Delta_Q m(x)=m(x;Q(w+\Delta w))-m(x;Q(w)).$$

Behavior survives if the relevant decision crosses or preserves the intended margin condition under deployment. For example, if the intervention is supposed to suppress a memorized answer by pushing its margin below zero, then success requires

$$m(x;Q(w+\Delta w)) < 0$$

on the unlearning slice, while preserving unrelated margins elsewhere.

Linearizing logits around $$w$$ gives a useful first-order predictor:

$$\Delta z(x) \approx J_w z(x;w)\Delta w,$$

and for the deployed path,

$$\Delta_Q z(x) \approx J_w z(x;\widehat{w})\Delta_Q w.$$

So two things can break:

  1. $$\Delta_Q w$$ differs from $$\Delta w$$ because quantization erased or aliased the update.
  2. The Jacobian at the quantized model $$J_w z(x;\widehat{w})$$ differs from the high-precision Jacobian because the model's local computation changed.

The first is an update-to-bin problem. The second is an activation/logit drift problem.

A survival scorecard

A deployment-validity audit should not report only final task accuracy. It should separate at least four quantities.

1. Update-to-bin exposure

For each edited coordinate or merged LoRA delta, estimate an effective local bin width $$b_i$$ and compute

$$\rho_i = \frac{|\Delta w_i|}{b_i}.$$

Summaries should be weighted by a relevance score, not just averaged over all weights. If $$s_i$$ is an attribution or sensitivity proxy, use

$$\bar{\rho}_{\mathrm{sens}} = \frac{\sum_i s_i\rho_i}{\sum_i s_i}.$$

The dangerous case is many high-sensitivity coordinates with $$\rho_i<1$$.

2. Deployed-delta fidelity

Compare the intended and deployed deltas:

$$\cos(\Delta w,\Delta_Q w) = \frac{\langle \Delta w,\Delta_Q w\rangle}{\|\Delta w\|\|\Delta_Q w\|}.$$

For LoRA-style low-rank updates, also inspect whether the deployed delta remains in the intended low-rank subspace. A quantization path can preserve norm but rotate the effective update toward outlier or scale artifacts.

3. Logit and activation drift

On target, neighboring, and control prompts, measure

$$D_z(x)=\|z(x;w+\Delta w)-z(x;Q(w+\Delta w))\|,$$

and the intervention-specific mismatch

$$D_{\Delta z}(x)=\|\Delta z(x)-\Delta_Q z(x)\|.$$

If hooks are cheap, also measure layerwise activation cosine drift:

$$C_\ell(x)=\frac{\langle h_\ell(x;w+\Delta w),h_\ell(x;Q(w+\Delta w))\rangle}{\|h_\ell(x;w+\Delta w)\|\|h_\ell(x;Q(w+\Delta w))\|}.$$

The important slice is not average drift. It is drift on prompts where the intervention's intended margin is small.

4. Behavior survival and specificity

Define target prompts $$T$$, neighboring prompts $$N$$, and unrelated controls $$C$$. A useful intervention changes $$T$$, minimally perturbs $$N$$ unless intended, and preserves $$C$$. Deployment survival can be summarized as

$$S_T = \mathbb{E}_{x\in T}\mathbf{1}[B_Q(x)=B_{\mathrm{intended}}(x)],$$

with analogous false-positive rates on $$N$$ and $$C$$. But also record margins, not only binary behavior, because quantization can leave behavior unchanged while reducing robustness.

Why full-precision validation can be actively misleading

The most dangerous case is not random degradation. It is conditional disagreement:

$$B(x;w+\Delta w)=\text{safe/refused/unlearned}, \qquad B(x;Q(w+\Delta w))=\text{unsafe/remembered/changed}.$$

This can happen even when average perplexity, MMLU, or broad safety pass rate barely moves. Model interventions are often sparse and slice-specific. Quantization error is also uneven: it clusters around outlier channels, sensitive layers, calibration blind spots, and low-margin prompts. Broad evals average over exactly the dimensions where failures are concentrated.

There is also the reverse case. Quantization can appear to make an intervention stronger by accidentally suppressing a target behavior. That is not necessarily success. If the effect comes from an aliasing artifact, it may not be stable across quantizers, group sizes, hardware kernels, or calibration sets.

So the claim should be phrased carefully:

The intervention is validated for a deployment path only if the intended causal effect survives that path with acceptable drift and specificity.

Not: “the fp16 intervention works, and the quantized model has similar benchmark accuracy.”

What to measure

For any edit/unlearning/refusal/LoRA/steering experiment that might be deployed low-bit, log:

  1. Quantization path: method, bit width, group size, per-channel/per-tensor scales, calibration data, outlier handling, activation/KV precision, and serving backend.
  2. Update-to-bin ratios:
$$ \rho_i=|\Delta w_i|/b_i$$

with sensitivity-weighted summaries and histograms for edited layers.

  1. Deployed-delta fidelity: norm ratio, cosine similarity, sign agreement, and low-rank subspace preservation between $$\Delta w$$ and $$\Delta_Q w$$.
  2. Target-slice margins: pre-edit, fp16 post-edit, and quantized post-edit margins on the exact behaviors the intervention claims to change.
  3. Logit/activation drift: especially on low-margin target and neighboring prompts, not only average prompts.
  4. Behavior survival: target success, neighbor false positives, unrelated-control regressions, and prompt paraphrase robustness.
  5. Quantizer sensitivity: repeat at least two paths, e.g. fp16 vs NF4-like and GGUF/AWQ/GPTQ-style, because survival under one quantizer is not a theorem.

Minimal experiment

Use one small model and one small, inspectable intervention.

  1. Pick an intervention type:

- a refusal steering vector;

- a tiny LoRA skill patch;

- a small unlearning/edit patch;

- a DPO/style delta;

- a rare-token or rare-fact fine-tune.

  1. Save the high-precision base model $$w$$ and edited model $$w+\Delta w$$.
  2. Quantize both through two deployment paths, for example:

- fp16 baseline;

- NF4/QLoRA-like path;

- GPTQ/AWQ path;

- GGUF/llama.cpp path;

- optional low-bit KV or optimized serving backend if logprobs are accessible.

  1. Build three prompt slices:

- target prompts where the edit should change behavior;

- near-neighbor prompts where overgeneralization would be bad;

- unrelated controls.

  1. Compute update-to-bin histograms, $$\Delta w$$ vs $$\Delta_Q w$$ cosine, target margins, logit drift, and behavior survival.
  2. Inspect failures by layer/channel group. Ask whether failures cluster where $$\rho_i<1$$, where outliers set the group scale, or where activation drift spikes.

A clean falsifier for deployment-validity anxiety would be:

$$\Delta_Q z(x)\approx \Delta z(x)$$

on target and neighbor slices across multiple quantization paths, with stable margins and no specificity loss. If that holds, the intervention is robust enough for that deployment family.

Failure modes

  1. Bin erasure: the important update coordinates have $$\rho_i<1$$ and round away.
  2. Boundary lottery: similar-sized updates behave differently because some coordinates sit near rounding thresholds and others sit near bin centers.
  3. Outlier scale coupling: one channel changes group scale, causing unrelated coordinates to move.
  4. Aliased intervention: the quantized delta has similar norm but different direction, so behavior changes for the wrong reason.
  5. Calibration mismatch: the quantizer's calibration data protects common behavior while damaging the intervention slice.
  6. Activation-path drift: parameters survive, but layer activations and logits move enough that the intended margin disappears.
  7. Backend-specific success: the edit survives one quantizer or kernel but fails under another common deployment path.
  8. Aggregate metric camouflage: average accuracy, perplexity, or safety pass rate remains stable while the exact target/neighbor slice fails.
