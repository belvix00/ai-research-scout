AI Research Scout Resources — 2026-05-19

Core DL/LLM research

arXiv — GQLA: Group-Query Latent Attention for Hardware-Adaptive Large Language Model Decoding

Type: Paper

Link: https://arxiv.org/abs/2605.15250v1

Summary: Proposes a hardware-adaptive variant around DeepSeek-style Multi-head Latent Attention, separating the trained latent-attention representation from a single absorbed decoding path. Collected because it turns attention layout into an explicit serving-time design variable rather than a fixed architecture choice. Mechanism signal: low-rank KV/latent state can be remapped to hardware rooflines, but the remapping itself should be tested for quality and rare-context drift.

Personalization: medium

arXiv — STS: Efficient Sparse Attention with Speculative Token Sparsity

Type: Paper

Link: https://arxiv.org/abs/2605.15508v1

Summary: Introduces sparse attention for long LLM inference by speculating which token interactions matter, targeting multi-million-token agentic contexts. This is useful because sparse attention is not just a throughput trick: it decides which evidence remains reachable. Mechanism signal: token-sparsity predictors need rare-evidence and distractor audits under equal latency/KV budgets.

Personalization: medium

arXiv — PSD: Pushing the Pareto Frontier of Diffusion LLMs via Parallel Speculative Decoding

Type: Paper

Link: https://arxiv.org/abs/2605.15609v1

Summary: Applies speculative-decoding ideas to diffusion language models, whose iterative masked-token denoising differs from autoregressive next-token decoding. Collected as a non-AR inference signal: acceleration may change trajectory quality, not only wall-clock time. Mechanism signal: diffusion LLMs need their own speculation diagnostics instead of importing AR acceptance-rate intuitions directly.

Personalization: low

Hugging Face Papers — Follow the Mean: Reference-Guided Flow Matching

Type: Paper

Link: https://huggingface.co/papers/2605.10302

Summary: Uses flow-matching structure to create a control interface based on reference examples rather than fine-tuning, auxiliary networks, or heavy test-time search. Collected because it is a clean example of controllability moving into the generative dynamics. Mechanism signal: compare whether reference-conditioned velocity changes preserve global factors more robustly than prompt or adapter control.

Personalization: low

Training/RL/math/mech interp

arXiv — GRLO: Towards Generalizable Reinforcement Learning in Open-Ended Environments from Zero

Type: Paper

Link: https://arxiv.org/abs/2605.15464v1

Summary: Frames open-ended RL post-training beyond the narrow verifiable-reward setup, trying to generalize from zero in environments where exploration and task structure matter. Collected because it adds to the ongoing shift from “which optimizer?” to “which rollout distribution and feedback channel?”. Mechanism signal: measure exploration diversity, trajectory novelty, and transfer rather than only final reward.

Personalization: medium

arXiv — Nudging Beyond the Comfort Zone: Efficient Strategy-Guided Exploration for RLVR

Type: Paper

Link: https://arxiv.org/abs/2605.15726v1

Summary: Targets a central RLVR failure: a model can only improve on strategies it samples, so policies get trapped in comfortable but narrow solution regions. Collected because it is directly about exploration geometry in reasoning post-training. Mechanism signal: strategy guidance should be audited for whether it creates genuinely new successful branches or merely reweights existing ones.

Personalization: medium

Hugging Face Papers — Hölder Policy Optimisation

Type: Paper

Link: https://huggingface.co/papers/2605.12058

Summary: Revisits how trajectory-level advantages are aggregated into token-level policy updates in GRPO-like training. Collected because the aggregation rule is a hidden credit-assignment interface, not a minor implementation detail. Mechanism signal: compare token-probability aggregation choices by prefix-local KL, changed-token sparsity, and gradient cosine on a fixed rollout set.

Personalization: medium

Hugging Face Papers — MetaAgent-X: Breaking the Ceiling of Automatic Multi-Agent Systems via End-to-End Reinforcement Learning

Type: Paper

Link: https://huggingface.co/papers/2605.14212

Summary: Trains automatic multi-agent system design end-to-end instead of relying only on manual orchestration or test-time search. Collected as an agent-RL lifecycle signal: the optimized object becomes the workflow, not just a single model’s response. Mechanism signal: log spawn/delegate/tool/aggregate events and check whether reward improves reusable coordination or overfits orchestration traces.

Personalization: medium

arXiv — When Are Two Networks the Same? Tensor Similarity for Mechanistic Interpretability

Type: Paper

Link: https://arxiv.org/abs/2605.15183v1

Summary: Proposes tensor-based similarity for deciding whether two model components implement the same computation, addressing limits of behavior-only or activation-only comparisons. Collected because interpretability units need equivalence tests before being trusted as mechanisms. Mechanism signal: evaluate against held-out intervention and patch-effect prediction, not only nearest-neighbor similarity.

Personalization: medium

arXiv — Exemplar Partitioning for Mechanistic Interpretability

Type: Paper

Link: https://arxiv.org/abs/2605.14347v1

Summary: Builds interpretable feature dictionaries from far fewer activation examples than typical SAE training. Collected as a cheap interpretability-method signal: reducing token requirements could make daily small-model audits more accessible. Mechanism signal: compare EP dictionaries with SAEs on causal ablation/patch predictions and side-effect specificity.

Personalization: medium

Hugging Face Papers — Forgetting That Sticks: Quantization-Permanent Unlearning via Circuit Attribution

Type: Paper

Link: https://huggingface.co/papers/2605.15138

Summary: Studies unlearning that remains effective after quantization, responding to evidence that low-bit deployment can reverse full-precision unlearning. Collected because it strengthens the deployment-path-validity theme. Mechanism signal: an intervention should be signed off through fp16 and actual quantized paths with update-to-bin ratios, logit drift, and target-margin survival.

Personalization: high

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.15044v1

Summary: Builds an audio-LLM specialized for speaker understanding and verification reasoning, aimed at authorization, personalization, and speaker-aware agents. Collected because speaker evidence is becoming a reasoning input, not just an embedding lookup. Mechanism signal: probe whether speaker identity, transcript content, accent, prosody, and verification rationale occupy separable subspaces.

Personalization: medium

arXiv — Streaming Speech-to-Text Translation with a SpeechLLM

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.14766v1

Summary: Combines speech recognition and translation in a SpeechLLM for streaming speech-to-text translation, potentially using paralinguistic information while reducing cascaded errors. Collected because streaming emission timing is a distinct audio factor. Mechanism signal: evaluate latency decisions, partial evidence, and speaker/prosody preservation separately from translation BLEU or WER.

Personalization: medium

arXiv — Improving Automatic Speech Recognition for Speakers Treated for Oral Cancer using Data Augmentation and LLM Error Correction

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.15854v1

Summary: Studies ASR for speakers with oral-cancer-related speech impairments using augmentation plus LLM-based correction. Collected because impaired-speech ASR exposes where generic speech models fail outside clean speech distributions. Mechanism signal: separate acoustic robustness from language-model correction; otherwise the correction layer can hide which phonetic factors were lost.

arXiv — Too Good to Be True: A Study on Modern Automatic Speech Recognition for the Evaluation of Speech Enhancement

Mechanism signal: ASR-based evaluation can reward recognizability while missing perceptual quality, speaker preservation, or enhancement artifacts.
