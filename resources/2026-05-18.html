AI Research Scout Resources — 2026-05-18

Plain resource list collected for the 2026-05-18 IST scout run. The day was heterogeneous: no single dominant pattern, but strong signals appeared around adaptive inference/state, RLVR credit shaping, MoE routing, interpretability-feature capacity, audio-agent evaluation, and deployment/quantization validity.

Core DL/LLM research

arXiv — MeMo: Memory as a Model

Type: Paper

Link: https://arxiv.org/abs/2605.15156v1

Summary: Proposes treating memory as an explicit model component rather than only longer prompts or periodic fine-tuning. This was collected because it sharpens the state-interface question: what information should live in weights, external memory, KV/session state, or retrieval? The learning value is a mechanism for timely domain adaptation without full model updates.

Personalization: medium

arXiv / HF Papers — Long Context Pre-Training with Lighthouse Attention

Type: Paper

Link: https://arxiv.org/abs/2605.06554v1

Summary: Uses a training-only hierarchical attention wrapper that compresses/decompresses sequence representations during most pretraining, then removes the approximation in a recovery phase. The mechanism is temporary lossy optimization: cheaper long-context training may work if rare/order-sensitive features recover. Code is linked from the paper, making this a concrete cheap-reproduction candidate.

Personalization: medium

Training/RL/math/mech interp

arXiv / HF Papers — Boosting Reinforcement Learning with Verifiable Rewards via Randomly Selected Few-Shot Guidance

Type: Paper

Link: https://arxiv.org/abs/2605.15012v1

Summary: FEST combines RLVR with only 128 randomly selected demonstrations and decays the supervised weight to avoid overfitting. It matters because it makes RLVR sample efficiency look like a balance between supervised anchoring and on-policy exploration, not a binary SFT-vs-RL choice. The mechanism to test is how few-shot guidance changes rollout diversity and sparse reward discovery.

Personalization: medium

arXiv — Self-Distilled Agentic Reinforcement Learning

Type: Paper

Link: https://arxiv.org/abs/2605.15155v1

Summary: Adds on-policy self-distillation to trajectory-level RL for long-horizon agents. The resource was collected because it widens sparse rewards into denser supervision, but may also copy stale mistakes or collapse strategy diversity. It is a direct signal for auditing teacher freshness, failure-step localization, and gradient direction in agentic RL.

Personalization: medium

arXiv / HF Papers — BEAM: Binary Expert Activation Masking for Dynamic Routing in MoE

Type: Paper

Link: https://arxiv.org/abs/2605.14438v1

Summary: Learns token-adaptive binary masks for MoE expert activation and reports large FLOP/latency reductions with a custom CUDA/vLLM integration. The mechanism is routing as an inference-time compute controller rather than fixed top-k selection. It is useful for probing whether dynamic expert masks preserve rare-feature experts or merely optimize average throughput.

Personalization: medium

arXiv — The Rate-Distortion-Polysemanticity Tradeoff in SAEs

Type: Paper

Link: https://arxiv.org/abs/2605.14694v1

Summary: Frames sparse autoencoders through a three-way tradeoff: reconstruction distortion, feature rate/sparsity, and polysemanticity. This is a mechanism-first interpretability resource because it explains why lower reconstruction error can still produce less useful features. It suggests SAE comparisons should include causal feature purity/intervention prediction, not only reconstruction metrics.

Personalization: medium

arXiv — Exemplar Partitioning for Mechanistic Interpretability

Type: Paper

Link: https://arxiv.org/abs/2605.14347v1

Summary: Introduces a dictionary-learning alternative that uses exemplar partitions and claims roughly three orders of magnitude fewer tokens than comparable SAEs. It was collected because cheaper dictionary construction changes the cost floor for local mechanistic interpretability experiments. The mechanism to verify is whether partition-derived features predict held-out patching/ablation effects, not just look interpretable.

Personalization: medium

OpenReview — Decomposing LLM Computation with Jets

Type: Paper

Link: https://openreview.net/forum?id=u6JLh0BO5h

Summary: Studies decomposition of entangled LLM computation into structured components called jets. This continues the recent internal-computation-unit thread: path/jet/neuron/SAE units need causal scoring, not just readability. The useful experiment is to ask whether a decomposition predicts held-out interventions or tuning interference better than ordinary activation similarity.

Audio/TTS/speech

OpenReview — From Text to Talk: Audio-Language Model Needs Non-Autoregressive Joint Training

Type: Audio/TTS

Link: https://openreview.net/forum?id=e3XLWHFrnr

Summary: Argues that speech-to-speech/audio-language models need non-autoregressive joint training rather than simply extending text-style autoregression. This is valuable because audio generation has different latency, continuity, and prosody constraints from text. The mechanism is objective mismatch between text token prediction and acoustic factor generation.

Personalization: medium

arXiv — SpeakerLLM: A Speaker-Specialized Audio-LLM for Speaker Understanding and Verification Reasoning

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.15044v1

Summary: Builds an audio-LLM specialized for speaker understanding and speaker-verification reasoning. The signal is that speaker identity is moving from a side embedding into a reasoning object for audio agents. It should be tested for factor separation: speaker evidence, transcript content, accent/language, and recording condition can easily entangle.

Personalization: medium

arXiv — From Text to Voice: A Reproducible and Verifiable Framework for Evaluating Tool Calling LLM Agents

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.15104v1

Summary: Converts text tool-calling benchmarks into controlled audio-based tool-use evaluations. The value is not a new TTS model but an evaluation mechanism: speech input introduces ASR/prosody/channel errors into the tool-call loop. It is useful for measuring whether voice agents fail because of language reasoning, audio perception, or schema execution.

Personalization: medium

arXiv — Towards Fine-Grained Multi-Dimensional Speech Understanding: Data Pipeline, Benchmark, and Model

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.12036v1

Summary: Targets speech understanding beyond basic transcription, emphasizing disentanglement of microphone/channel, speaker, emotion, content, and other dimensions. Collected because it fits the speech-factor survival theme and may provide benchmark structure for probes. The mechanism is multi-factor acoustic perception rather than WER-only ASR improvement.

BAIR — Adaptive Parallel Reasoning: The Next Paradigm in Efficient Inference Scaling

Type: Lab blog

Link: http://bair.berkeley.edu/blog/2026/05/08/adaptive-parallel-reasoning/

Summary: Presents adaptive parallel reasoning as an inference-scaling alternative to fixed serial test-time compute. It was collected because it changes the controller question: when should a model branch, parallelize, stop, or allocate more computation? The mechanism is uncertainty/utility-based compute allocation rather than a single longer chain of thought.

arXiv — An Interpretable Latency Model for Speculative Decoding in LLM Serving

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.15051v1

Summary: Builds an interpretable latency model for speculative decoding rather than treating speedup as an empirical black box. This is useful because speculation changes not just tokens/sec but acceptance dynamics and serving economics. It provides knobs for choosing draft/target settings under workload constraints and for finding where speedups collapse.

Personalization: medium

arXiv — KVServe: Service-Aware KV Cache Compression for Communication-Efficient Disaggregated LLM Serving

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.13734v1

Summary: Treats KV cache as a communication object in disaggregated prefill/decode serving. Collected because KV compression is now a deployment interface that can decide which context state survives across machines. The important mechanism is service-aware compression under latency/bandwidth constraints, which should be audited on rare-evidence prompts.

Personalization: medium

arXiv — AB-Sparse: Sparse Attention with Adaptive Block Size for Accurate and Efficient Long-Context Inference

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.12110v1

Summary: Uses adaptive block-size sparse attention to reduce long-context KV loading while preserving accuracy. It matters because sparse attention is an evidence-retention policy, not merely a speedup. The mechanism to test is whether adaptive block selection keeps low-frequency decisive facts or over-prunes rare early evidence.

Type: Infra/GPU

Summary: Argues inference evaluation should include energy-to-token production under quality constraints, not only latency, throughput, and utilization. This is a broad infra/resource-accounting signal. It helps normalize local and deployed experiments by cost, energy, and quality rather than headline speed alone.

Broad learning / outside current project bubble

arXiv / HF Papers — Aligning Latent Geometry for Spherical Flow Matching in Image Generation

Type: Paper

Link: https://arxiv.org/abs/2605.15193v1

Summary: Shows that image VAE latents concentrate on spherical shells and argues that semantic/perceptual content is mostly angular, not radial. It replaces linear latent flow paths with spherical/geodesic paths while leaving the diffusion architecture unchanged. This is outside Aman's immediate LLM bubble but useful for learning how representation geometry changes the objective path.

Skeptical or failure signal

arXiv — Widening the Gap: Exploiting LLM Quantization via Outlier Injection

Type: Paper

Link: https://arxiv.org/abs/2605.15152v1

Summary: Shows that quantization can be exploited by injecting outliers so a model looks benign in full precision but behaves differently when deployed low-bit. This is a strong skeptical signal for any intervention or safety claim evaluated only before quantization. The mechanism is deployment-path aliasing: quantizers can turn small outlier structure into large behavioral differences.

Personalization: high

arXiv — Forgetting That Sticks: Quantization-Permanent Unlearning via Circuit Attribution

Type: Paper

Link: https://arxiv.org/abs/2605.15138v1

Summary: Studies unlearning that remains effective after quantization, using circuit attribution to target edits. It pairs with the outlier-injection result as a two-sided signal: quantization can either break or preserve interventions depending on where the edit lives. The learning value is to evaluate model edits through the deployed precision path.

Personalization: high

arXiv — LiSA: Lifelong Safety Adaptation via Conservative Policy Induction

Type: Paper

Link: https://arxiv.org/abs/2605.14454v1

Summary: Proposes adapting fixed guardrails from sparse, noisy deployment feedback using structured memory, conflict-aware local rules, and confidence gating. It is a skeptical/deployment signal because pre-deployment safety rules are underspecified for local contexts. The mechanism to inspect is when sparse failure memory generalizes vs overgeneralizes.
