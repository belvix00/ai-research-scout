AI Research Scout Resources — 2026-05-16

Core DL/LLM research

arXiv — MeMo: Memory as a Model

Type: Paper

Link: https://arxiv.org/abs/2605.15156v1

Summary: A modular knowledge-update approach that encodes new information into a separate memory model while keeping the base LLM frozen. The mechanism is interesting because retrieval cost is claimed to be independent of corpus size and the method does not require base-model weights or logits, making it a plug-in alternative to RAG/fine-tuning for closed models. Collected as a memory-architecture signal, not as generic agent hype.

Personalization: medium

arXiv — ATLAS: Agentic or Latent Visual Reasoning? One Word is Enough for Both

Type: Paper

Link: https://arxiv.org/abs/2605.15198v1

Summary: Proposes “functional tokens” that act both as discrete agentic operations and latent visual reasoning units. The useful mechanism is a tokenizer-compatible way to internalize visual operations without generating verbose intermediate images or relying on external tool calls. It belongs in the broader model-mechanism bucket because it treats an ordinary next-token target as a carrier for latent computation.

Personalization: low

Hugging Face Papers / arXiv — Achieving Gold-Medal-Level Olympiad Reasoning via Simple and Unified Scaling

Type: Paper

Link: https://huggingface.co/papers/2605.13301

Summary: Describes a unified recipe for turning a post-trained reasoning backbone into an olympiad solver: reverse-perplexity SFT curriculum, RL with verifiable rewards, proof-level RL, and test-time scaling. The mechanism value is the staged curriculum and RL handoff, especially the claim that long trajectories beyond 100K tokens can be stabilized with only hundreds of RL steps. Useful as evidence about reasoning-training lifecycle rather than leaderboard watching.

Personalization: medium

Hugging Face Blog / Allen AI — EMO: Pretraining mixture of experts for emergent modularity

Type: Lab blog

Link: https://huggingface.co/blog/allenai/emo

Summary: A research blog on pretraining mixture-of-experts models for emergent modularity. It remains relevant because MoE is increasingly being framed as learned modular capacity rather than just sparse compute, matching recent signals around shared experts, routing, and feature allocation. Collected for architecture/training-dynamics learning, especially router specialization and expert reuse.

Training/RL/math/mech interp

arXiv — Self-Distilled Agentic Reinforcement Learning

Type: Paper

Link: https://arxiv.org/abs/2605.15155v1

Summary: Introduces SDAR, a gated self-distillation objective for multi-turn agent RL that keeps RL primary while using privileged teacher signals as a token-level auxiliary target. The mechanism is a sigmoid gate that strengthens teacher-endorsed positive-gap tokens while softening negative rejections that may reflect imperfect skill retrieval. This is high-signal for the recurring question of where dense supervision should enter long-horizon agent training.

Personalization: medium

arXiv — Learning from Language Feedback via Variational Policy Distillation

Type: Paper

Link: https://arxiv.org/abs/2605.15113v1

Summary: Formalizes language-feedback learning as variational EM: a teacher is actively refined from trajectory outcomes, then the student distills the teacher’s token distributions on on-policy rollouts. The mechanism addresses sparse RLVR rewards by making textual critique into dense supervision while avoiding a fixed teacher bottleneck. Collected as a training-objective signal for reasoning/RL systems.

Personalization: medium

OpenReview — Decomposing LLM Computation with Jets

Type: Mech interp

Link: https://openreview.net/forum?id=u6JLh0BO5h

Summary: An ICLR 2026 OpenReview submission about decomposing LLM computation using jets. It was collected because it directly targets modularizing entangled LLM computations for interpretability and auditing, continuing the path/feature decomposition line. The important learning value is whether internal computational components can predict interventions rather than merely explain them post hoc.

Personalization: medium

arXiv — When Are Two Networks the Same? Tensor Similarity for Mechanistic Interpretability

Type: Mech interp

Link: https://arxiv.org/abs/2605.15183v1

Summary: Proposes a weight-based tensor-similarity metric invariant to weight-space symmetries for tensor-based models. It claims to track functional training dynamics such as grokking and backdoor insertion better than empirical-behavior or basis-dependent parameter comparisons. Useful as a mathematically crisp way to ask when two mechanisms are “the same” beyond surface behavior.

Personalization: low

arXiv — Forgetting That Sticks: Quantization-Permanent Unlearning via Circuit Attribution

Type: Mech interp

Link: https://arxiv.org/abs/2605.15138v1

Summary: Shows that full-precision unlearning can be undone by 4-bit quantization because many updates are far below NF4 bin widths. The proposed MANSU method uses circuit attribution, null-space projection, and a per-parameter magnitude floor so forgetting survives compression. This is both a mechanistic unlearning result and a warning that deployment quantization changes the effective intervention.

Personalization: medium

Optimization Online — Inexact Cubic Regularization Method with Adaptive Reuse of Hessian Approximations

Type: Math/theory

Link: https://optimization-online.org/2026/05/inexact-cubic-regularization-method-with-adaptive-reuse-of-hessian-approximations/?utm_source=rss&utm_medium=rss&utm_campaign=inexact-cubic-regularization-method-with-adaptive-reuse-of-hessian-approximations

Summary: A nonconvex optimization method that reuses Hessian approximations lazily while updating gradients inexactly. It is not an LLM paper, but it is useful background for thinking about second-order information under compute constraints. Collected as broad optimization learning, not as an immediate project lead.

Audio/TTS/speech

arXiv — Streaming Speech-to-Text Translation with a SpeechLLM

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.14766v1

Summary: Builds a streaming SpeechLLM that learns both when to emit translated text and what to emit, rather than waiting for complete utterances. The mechanism is aligned speech/text training that turns emission timing into a learned decision and reaches 1–2 second latency while staying close to non-streaming quality. Good signal for audio agents where latency, not just WER/BLEU, is part of the model behavior.

Personalization: medium

arXiv — SpeakerLLM: A Speaker-Specialized Audio-LLM for Speaker Understanding and Verification Reasoning

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.15044v1

Summary: Unifies speaker profiling, recording-condition understanding, utterance-pair comparison, and verification reasoning in a natural-language audio-LLM interface. The mechanism value is evidence-organized verification: separating recording conditions, profile evidence, and final same/different decisions. It expands the speech-factor probe beyond content transcription into identity and condition reasoning.

Personalization: medium

arXiv — Minimizing Modality Gap from the Input Side: Your Speech LLM Can Be a Prosody-Aware Text LLM

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.05927v2

Summary: Argues that the bottleneck in speech LLMs is often the input-side modality gap, and combines synchronized text tokens with prosody embeddings before the LLM. The notable signal is data efficiency: about 1,000 hours of audio training reportedly reduces the speech/text gap at 3B and 7B scale. Collected because it directly tests where speech information should enter a text-LM backbone.

Personalization: medium

arXiv — Kinetic-Optimal Scheduling with Moment Correction for Metric-Induced Discrete Flow Matching in Zero-Shot Text-to-Speech

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.09386v1

Summary: Improves discrete flow matching for codec-based zero-shot TTS by deriving a Fisher-Rao-speed scheduler and a finite-step moment correction for CTMC path tracking. The mechanism is numerical rather than architectural: better schedules and moment corrections reduce heuristic search and finite-step error. Useful for understanding why flow/diffusion-style TTS quality can depend heavily on solver/path details.

Personalization: low

Inference/ML infra/GPU

arXiv — An Interpretable Latency Model for Speculative Decoding in LLM Serving

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.15051v1

Summary: Provides a latency model for speculative decoding under variable production load, decomposing prefill, drafting, and verification while inferring effective batch size with Little’s Law. The main signal is that speculative decoding speedups can diminish as load increases, so acceptance rate and draft length cannot be studied in isolation. Collected for inference-systems mechanism and experiment-design value.

Personalization: medium

arXiv — Self-Pruned Key-Value Attention: Learning When to Write by Predicting Future Utility

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.14037v1

Summary: Trains a lightweight utility predictor jointly with the LM to decide which older key-value pairs deserve long-term cache writes. The mechanism is dynamic KV sparsification through next-token loss, not a fixed compression rule, with reported 3–10× cache reduction. This is a strong signal for treating cache write policy as a learned model component.

Personalization: medium

arXiv — Minimal-Intervention KV Retention: A Design-Space Study and a Diversity-Penalty Survivor

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.14292v1

Summary: Tests several KV-retention mechanisms under matched mean cache budgets for long-form mathematical reasoning and finds most fail. A simple diversity-penalty modification to a retention scorer survives in some pre-registered cells, suggesting that anti-redundancy in value space may matter more than heavier structural redesigns. Collected as a useful negative/positive design-space signal.

Personalization: medium

arXiv — Attention Once Is All You Need: Efficient Streaming Inference with Stateful Transformers

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.13784v1

Summary: Moves transformer streaming workloads from request-driven prefill to persistent stateful sessions with incrementally advanced KV caches. The useful mechanism is not just speedup but an alternative computational model: data-driven sessions and “Flash Queries” can pre-evaluate registered questions during idle GPU cycles. Relevant for long-lived agents, monitoring, and streaming contexts.

Personalization: medium

Skeptical or failure signal

arXiv — Widening the Gap: Exploiting LLM Quantization via Outlier Injection

Type: Skeptical or failure signal

Link: https://arxiv.org/abs/2605.15152v1

Summary: Demonstrates a quantization-conditioned attack where injected outliers cause predictable weight collapse under advanced schemes such as AWQ, GPTQ, and GGUF I-quants. The key failure mechanism is that apparently benign full-precision checkpoints can become malicious after ordinary deployment quantization. This should temper confidence in model cards/evals that do not test the deployed low-bit path.

Personalization: medium
