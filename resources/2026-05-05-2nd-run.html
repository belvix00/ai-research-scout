AI Research Scout Resources — 2026-05-05 2nd run

Core DL/LLM research

arXiv — Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces

Type: Paper

Link: https://arxiv.org/abs/2605.02801v1

Summary: This paper reframes multi-agent LLM systems as temporal orchestration traces: spawn, delegate, communicate, call tools, aggregate, and stop. It is useful because the learning target is not just a final answer but the control graph that produced it. The mechanism signal is credit assignment over agent topology and timing, which is broader than prompt-level agent evaluation.

Personalization: medium

arXiv — SCPRM: A Schema-aware Cumulative Process Reward Model for Knowledge Graph Question Answering

Type: Paper

Link: https://arxiv.org/abs/2605.02819v1

Summary: SCPRM targets a risk-compensation failure in process reward models: bad intermediate reasoning can be masked by later plausible steps. It adds schema-aware cumulative scoring for KG reasoning paths, making the intermediate path itself the supervised object. The mechanism signal is stepwise reward decomposition under multiple valid paths, relevant to reasoning supervision beyond final-answer grading.

Personalization: low

arXiv — Perceptual Flow Network for Visually Grounded Reasoning

Type: Paper

Link: https://arxiv.org/abs/2605.02730v1

Summary: PFlowNet argues that ordinary LVLM training and geometric expert priors can still leave visual reasoning biased toward language or low-level geometry. It tries to create interpretable visual trajectories that are optimized for reasoning utility rather than rigid expert alignment. The useful signal is a visual-grounding objective that treats perception as a path/process, not only as static tokens.

Personalization: medium

Hugging Face Blog — Granite 4.1 LLMs: How They’re Built

Type: Lab blog

Link: https://huggingface.co/blog/ibm-granite/granite-4-1

Summary: This model-build post is worth scanning for architecture, data, training, and deployment choices rather than benchmark deltas. Granite-family writeups often expose pragmatic decisions around enterprise-sized open models, safety tuning, and inference constraints. The signal is not “new model released” but how a production-oriented LLM stack trades off size, data quality, alignment, and serving cost.

Training/RL/math/mech interp

arXiv — Gradient-Gated DPO: Stabilizing Preference Optimization in Language Models

Type: Paper

Link: https://arxiv.org/abs/2605.02626v1

Summary: The paper studies a DPO squeezing effect where negative gradients on rejected responses concentrate probability mass on already high-confidence predictions and suppress alternatives. Gradient-gated DPO is proposed as a stabilizer for this preference-optimization pathology. This is a clean mechanism signal: alignment objectives can reshape probability geometry in ways that look like collapse before aggregate metrics expose it.

Personalization: medium

arXiv — Trust, but Verify: Peeling Low-Bit Transformer Networks for Training Monitoring

Type: Paper

Link: https://arxiv.org/abs/2605.02853v1

Summary: This work proposes a layer-wise peeling framework to monitor whether low-bit transformer layers are actually optimized well. It builds lightweight local probes against intermediate representations, turning “training worked” into a layer-specific diagnostic. The mechanism signal is monitoring hidden optimization quality under quantization or frozen-reuse constraints, not just final loss.

Personalization: medium

OpenReview — Decomposing LLM Computation with Jets

It is worth tracking as a possible bridge between circuit decomposition, feature geometry, and intervention-ready model components.

OpenReview — Neuron-Aware Data Selection in Instruction Tuning for Large Language Models

Type: Mech interp

Link: https://api2.openreview.net/notes?content.venueid=ICLR.cc%2F2026%2FConference&limit=5

Summary: This submission selects instruction-tuning data using neuron activation similarity between candidate examples and target domains. The key signal is that data selection can be driven by internal computation rather than text or embedding similarity alone. It supports a small experiment comparing random, semantic-similar, and activation-similar instruction subsets for sample efficiency and interference.

Apple ML Research — PORTool: Importance-Aware Policy Optimization with Rewarded Tree for Multi-Tool-Integrated Reasoning

Type: Lab blog

Link: https://machinelearning.apple.com/research/portool-policy-optimization

Summary: PORTool attacks outcome-only credit assignment in tool-use agents by building a rewarded tree and assigning step-level importance to tool decisions. This is a strong RL-for-agents signal because the policy gradient is moved closer to the actual tool call that mattered. It complements process reward modeling and orchestration-trace RL: the object to train is the interaction path, not only the final response.

Apple ML Research — Adaptive Thinking: Large Language Models Know When to Think in Latent Space

Type: Lab blog

Link: https://machinelearning.apple.com/research/adaptive-thinking

Summary: The post uses self-consistency as a proxy for deciding when extra latent thinking is needed. This contributes to the recurring adaptive-compute theme: spend reasoning budget when uncertainty or disagreement says the query is hard, not by a fixed token schedule. The mechanism signal is compute gating by internal confidence structure.

Audio/TTS/speech

arXiv — Multi-Axis Speech Similarity via Factor-Partitioned Embeddings

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.02804v1

Summary: This paper explicitly partitions speech embeddings into axes such as linguistic content, speaker identity, dialect, and gender, then retrieves by signed weighted similarity across axes. It directly targets the usual single-vector conflation problem in speech representations. The mechanism signal is factorized audio geometry: similarity becomes controllable by speech attribute rather than globally entangled.

Personalization: medium

arXiv — When Audio-Language Models Fail to Leverage Multimodal Context for Dysarthric Speech Recognition

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.02782v1

Summary: This benchmark tests whether audio-language models actually use diagnosis labels, clinical ratings, or descriptions to improve dysarthric speech recognition. The reported signal is skeptical: current models often do not meaningfully exploit the provided multimodal context. This is valuable because it separates “can condition on extra text” from “uses context causally for hard speech.”

Personalization: low

arXiv — Toward Fine-Grained Speech Inpainting Forensics: A Dataset, Method, and Metric for Multi-Region Tampering Localization

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.02223v1

Summary: MIST targets partial speech manipulation where only a few words are replaced while speaker identity is preserved. The task is multi-region localization, not utterance-level fake detection, so it stresses temporal and semantic boundaries in synthesized audio. The mechanism signal is forensic localization over codec/TTS edits, useful for understanding how speech generators hide or reveal local tampering.

Personalization: low

arXiv — Tibetan-TTS: Low-Resource Tibetan Speech Synthesis with Large Model Adaptation

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.02496v1

Summary: This work adapts a large speech synthesis model to low-resource Tibetan using data-quality improvement, Tibetan-specific text/tokenizer handling, and cross-lingual adaptation. The interesting signal is how much of TTS quality comes from representation and tokenizer adaptation rather than model scale alone. It is a practical low-resource speech recipe to compare against codec-token and factor-probe ideas.

Inference/ML infra/GPU

arXiv — SpecKV: Adaptive Speculative Decoding with Compression-Aware Gamma Selection

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.02888v1

Summary: SpecKV adapts the speculative-decoding draft length per step using signals tied to compression level and generation state. Fixed gamma is treated as a bad default because optimal speculation depends on task and target-model compression. The mechanism signal is inference-time control: speculative decoding becomes a feedback controller rather than a static serving parameter.

Personalization: medium

arXiv — StreamIndex: Memory-Bounded Compressed Sparse Attention via Streaming Top-k

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.02568v1

Summary: StreamIndex tackles the huge intermediate score tensor in compressed sparse attention by using chunked partition-merge top-k in Triton. The paper is useful because it identifies the hidden memory object that makes sparse attention impractical at long sequence lengths. The mechanism/tooling signal is streaming selection as the bottleneck remover for learned sparse attention.

Personalization: medium

PyTorch Blog — SMG: The Case for Disaggregating CPU from GPU in LLM Serving

Type: Infra/GPU

Link: https://pytorch.org/blog/lightseek-smg/

Summary: This serving post argues that CPU-side orchestration can bottleneck large-scale LLM serving and motivates separating CPU gateway work from GPU execution. It is useful as an infra signal because prefill/decode kernels are not the only bottleneck; scheduling, Python/runtime overhead, and request routing also shape effective throughput. The mechanism is serving-stack decomposition under production load.

PyTorch Blog — Introducing AutoSP

Type: Infra/GPU

Link: https://pytorch.org/blog/introducing-autosp/

Summary: AutoSP automatically converts ordinary transformer training code into sequence-parallel code for long-context training across GPUs. This lowers the friction of testing long-context models without hand-rewriting the distributed layout. The key tooling signal is compiler/runtime support for sequence parallelism as an experiment enabler, not merely an optimization detail.
