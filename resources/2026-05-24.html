arXiv — Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention

Type: Paper

Link: https://arxiv.org/abs/2605.22791v1

Summary: A linear-attention architecture paper that treats recurrent state updates as an edit operation with separable erase and write controls. The useful mechanism is memory editing under constant-cache decoding: compressed state models need to forget stale associations without corrupting useful ones. Collected because it gives a concrete architectural handle on the long-context/state-carrier question beyond softmax attention.

Personalization: medium

arXiv — WorldKV: Efficient World Memory with World Retrieval and Compression

Type: Paper

Link: https://arxiv.org/abs/2605.22718v1

Summary: Proposes trainable KV retrieval/compression for autoregressive video/world models where persistent scene consistency conflicts with real-time rollout cost. The mechanism signal is memory as a selective world-state cache, not just a generic KV-size reduction. It is useful for thinking about how state carriers preserve rare or revisited evidence under streaming constraints.

Personalization: medium

arXiv — The Matching Principle: A Geometric Theory of Loss Functions for Nuisance-Robust Representation Learning

Type: Math/theory

Link: https://arxiv.org/abs/2605.22800v1

Summary: Frames many robustness and invariance losses as one geometric problem: estimate deployment nuisance covariance and regularize encoder Jacobians along matching directions. The learning value is a mathematical mechanism for when invariance objectives preserve labels versus erase useful factors. Collected as broad DL theory with direct relevance to speech, vision, and representation robustness.

Personalization: low
