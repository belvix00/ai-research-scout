AI Research Scout Resources — 2026-05-06 2nd run

Bucket: Core DL/LLM research

arXiv — Transformers with Selective Access to Early Representations

Type: Paper

Link: https://arxiv.org/abs/2605.03953v1

Summary: A transformer architecture paper asking whether later layers should recover early low-level representations through selective access rather than static residual value reuse. It is useful because it treats depth as a lossy information pipeline: some token/head/context combinations may need early features more than others. The mechanism signal is adaptive early-representation routing under memory/throughput constraints.

Personalization: medium

arXiv — Task Vector Geometry Underlies Dual Modes of Task Inference in Transformers

Type: Paper

Link: https://arxiv.org/abs/2605.03780v1

Summary: A controlled small-transformer study of task-vector geometry for two modes of in-context learning: recognizing tasks seen during training and adapting to novel tasks. It connects internal representation directions to training distribution structure and OOD behavior. The learning value is a clean synthetic setup for turning interpretability observations into falsifiable geometry claims.

Personalization: medium

arXiv — Conditional Diffusion Sampling

Type: Paper

Link: https://arxiv.org/abs/2605.04013v1

Summary: A diffusion sampling paper about conditioning generative processes rather than only training a new model. It belongs here as a broad generative-model mechanism signal: inference-time sampling choices can change which parts of a learned distribution are reachable or emphasized. Useful for thinking about sampling as an algorithmic control surface, not just a final decoding detail.

Personalization: low

arXiv — Flow Sampling: Learning to Sample from Unnormalized Densities via Denoising Conditional Processes

Type: Paper

Link: https://arxiv.org/abs/2605.03984v1

Summary: A density/sampling method that frames sampling from unnormalized targets through denoising conditional processes. The DL learning value is mathematical: it gives another bridge between diffusion-style denoising, flow-like transports, and practical sampler construction. It is broad, but relevant to understanding generative training/inference dynamics.

Personalization: low

Bucket: Training/RL/math/mech interp

arXiv — Nora: Normalized Orthogonal Row Alignment for Scalable Matrix Optimizer

Type: Paper

Link: https://arxiv.org/abs/2605.03769v1

Summary: A matrix-optimizer proposal aiming to combine Muon-like preconditioning, scale-invariance stability, and low overhead. This is high-signal for LLM training dynamics because optimizer geometry increasingly matters as much as architecture at fixed compute. The mechanism to track is whether row-orthogonal normalization reduces radial jitter while preserving useful preconditioning.

Personalization: medium

arXiv — Steer Like the LLM: Activation Steering that Mimics Prompting

Type: Mech interp

Link: https://arxiv.org/abs/2605.03907v1

Summary: The paper reframes prompt steering as an activation intervention and argues that common steering vectors fail because prompting applies strong, token-specific interventions rather than uniform shifts. It introduces Prompt Steering Replacement models to approximate that tokenwise pattern. The important mechanism is sparsity/locality of control in activation space.

Personalization: medium

arXiv — Correct Is Not Enough: Training Reasoning Planners with Executor-Grounded Rewards

Type: Paper

Link: https://arxiv.org/abs/2605.03862v1

Summary: TraceLift treats reasoning traces as intermediate artifacts consumed by an executor, not as text that merely needs a correct final answer. It rewards planner traces according to executor-grounded utility, targeting right-answer-for-wrong-reason failures. This is useful for RL/RLHF because it moves credit assignment from outcome correctness to trace usefulness.

Personalization: medium

arXiv — Agentic-imodels: Evolving agentic interpretability tools via autoresearch

Type: Mech interp

Link: https://arxiv.org/abs/2605.03808v1

Summary: This paper asks a strange but useful question: if agents will analyze data, should tools be interpretable to agents rather than only humans? It evolves scikit-learn-compatible regressors using a predictive metric plus an LLM-based interpretability score. The mechanism signal is tool representation as an interface between automated researchers and statistical structure.

Personalization: low

Bucket: Audio/TTS/speech

arXiv / HF Papers — The TTS-STT Flywheel: Synthetic Entity-Dense Audio Closes the Indic ASR Gap

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.03073v1

Summary: A practical speech paper showing that entity-dense Telugu/Indic code-mix ASR failures can be attacked with a cheap synthetic TTS-to-STT data loop and LoRA fine-tuning. The collected mechanism is data curriculum targeted at rare entity classes rather than generic speech pretraining. It is also a good failure signal against relying on WER averages for niche domains.

Personalization: medium

arXiv — MiniMind-O Technical Report: An Open Small-Scale Speech-Native Omni Model

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.03937v1

Summary: MiniMind-O is a 0.1B-scale open omni model with text, speech, and image inputs plus streaming speech output. The report is useful because it exposes a small inspectable Thinker/Talker split, frozen speech/image encoders, modality projectors, and released training data. It makes speech-native multimodal architecture experiments cheaper than frontier-scale omni models.

Personalization: high

arXiv — PHALAR: Phasors for Learned Musical Audio Representations

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.03929v1

Summary: PHALAR uses learned spectral pooling and a complex-valued head to encode pitch- and phase-equivariant biases for musical stem retrieval. It reportedly improves retrieval while reducing parameters and training time. The conceptual signal is that audio representation learning still benefits from explicit symmetry/phase structure rather than generic semantic embeddings alone.

Personalization: low

arXiv — A Comprehensive Analysis of Tokenization and Self-Supervised Learning in End-to-End ASR applied on French

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.03696v1

Summary: This ASR study looks beyond WER/CER to qualitative effects of tokenization and self-supervised choices in French end-to-end speech recognition. It is useful because tokenization decisions can systematically change downstream transcript utility even when headline error rates look similar. The mechanism signal is speech-token granularity as a latent bottleneck.

Personalization: medium

Bucket: Inference/ML infra/GPU

arXiv — QKVShare: Quantized KV-Cache Handoff for Multi-Agent On-Device LLMs

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.03884v1

Summary: QKVShare studies quantized KV-cache transfer between on-device agents, with token-level mixed precision, a CacheCard representation, and HuggingFace-compatible cache injection. It is exactly the kind of inference mechanism that changes experiment feasibility: latent context can be shared without full re-prefill. The caveat is that benefits are clearest under deeper-hop/high-budget handoffs.

Personalization: high

PyTorch Blog — In-Kernel Broadcast Optimization: Co-Designing Kernels for RecSys Inference

Type: Infra/GPU

Link: https://pytorch.org/blog/in-kernel-broadcast-optimization-co-designing-kernels-for-recsys-inference/

Summary: A systems post on eliminating explicit replication of shared embeddings/sequences by fusing broadcast logic into inference kernels. Although framed around recommendation inference, the lesson generalizes to ML serving: remove redundant memory movement at the kernel/model boundary. The mechanism is kernel-level co-design around repeated context rather than only operator speedups.

Personalization: low

PyTorch Blog — Introducing AutoSP

Type: Infra/GPU

Link: https://pytorch.org/blog/introducing-autosp/

Summary: AutoSP automatically converts standard transformer training code into sequence-parallel code for long-context multi-GPU training. It is useful because it lowers the friction of long-context experiments where memory, communication, and sharding details often dominate the research iteration loop. The mechanism is compiler/tooling automation for sequence dimension partitioning.

Bucket: Skeptical or failure signal

arXiv — Safety and accuracy follow different scaling laws in clinical large language models

Type: Paper

Link: https://arxiv.org/abs/2605.04039v1

Summary: SaFE-Scale argues that clinical accuracy and safety do not improve identically with model scale, context, retrieval, or inference-time compute. It is a skeptical signal against assuming better average answers imply safer deployment behavior. The transferable mechanism is metric divergence under scale: high-risk errors can follow a different curve from aggregate task accuracy.

Personalization: low

arXiv — MOSAIC-Bench: Measuring Compositional Vulnerability Induction in Coding Agents

Type: Paper

Link: https://arxiv.org/abs/2605.03952v1

Summary: MOSAIC-Bench tests coding agents on vulnerability chains assembled from apparently innocuous subtasks, with deterministic exploit oracles. The failure mechanism is compositional compliance: local safety checks can pass while a sequenced end-state becomes malicious. This is a useful guardrail for agent training/evaluation work because it measures trajectory-level risk.
