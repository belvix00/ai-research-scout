AI Research Scout Resources — 2026-05-05

Plain list of resources collected today. Keep it scan-friendly.

Hugging Face Daily Papers — From Skill Text to Skill Structure: The Scheduling-Structural-Logical Representation for Agent Skills

Link: https://huggingface.co/papers/2604.24026

Summary: Proposes turning text-heavy agent skills into explicit structured representations covering invocation interfaces, execution structure, constraints, and side effects. The signal is not “another agent paper”; it is that skill memory may need a schema more like a program representation than a markdown note. Collected because Aman’s scout itself uses reusable skills and because agent memory/tool-use interfaces are a priority area.

Hugging Face Daily Papers — Learning while Deploying: Fleet-Scale Reinforcement Learning for Generalist Robot Policies

Link: https://huggingface.co/papers/2605.00416

Summary: Describes offline-to-online reinforcement learning for pretrained vision-language-action robot policies using fleet rollouts and human interventions. The useful mechanism is a deployed-policy data flywheel with value-learning stabilization for heterogeneous sparse-reward feedback. Collected as a strong RL/training-dynamics signal for “learning after deployment,” even outside robotics.

Hugging Face Daily Papers — Let ViT Speak: Generative Language-Image Pre-training

Link: https://huggingface.co/papers/2605.00809

Summary: GenLIP trains a ViT to predict language tokens directly from visual tokens using a standard language-modeling objective, without contrastive batch construction or an extra text decoder. The signal is a simpler alignment interface between vision encoders and autoregressive LMs. Collected because it suggests a probeable question: what changes when the vision tower receives token-level generative gradients instead of contrastive gradients?

Hugging Face Daily Papers — Trees to Flows and Back: Unifying Decision Trees and Diffusion Models

Link: https://huggingface.co/papers/2605.00414

Summary: Establishes a mathematical correspondence between hierarchical decision trees and diffusion processes in limiting regimes, with a shared Global Trajectory Score Matching principle. The practical claims include tabular generation speedups and distilling hierarchical decision logic into neural networks. Collected because it is a theory/mechanism bridge between discrete routing, continuous generative dynamics, and distillation.

Hugging Face Daily Papers — End-to-End Autoregressive Image Generation with 1D Semantic Tokenizer

Link: https://huggingface.co/papers/2605.00503

Summary: Jointly optimizes a 1D visual tokenizer and autoregressive generator so generation losses directly supervise the tokenizer, instead of using the common two-stage tokenizer-then-generator pipeline. The signal is that tokenizers are becoming trainable interfaces rather than fixed preprocessing. Collected because tokenizer bottlenecks are a recurring mechanism in multimodal and audio models.

Hugging Face Daily Papers — LASE: Language-Adversarial Speaker Encoding for Indic Cross-Script Identity Preservation

Link: https://huggingface.co/papers/2605.00777

Summary: Shows that multilingual speaker encoders can leak script/language information into speaker identity, with accent-conditional failures in cross-script voice cloning. LASE uses a frozen WavLM projection head with supervised contrastive identity loss plus gradient reversal against script classification. Collected because it is a concrete audio representation disentanglement problem with a small, testable adversarial-probe setup.

Hugging Face Daily Papers — MASCing: Configurable Mixture-of-Experts Behavior via Activation Steering Masks

Link: https://huggingface.co/papers/2604.27818

Summary: Proposes configuring MoE model behavior by learning activation/routing steering masks instead of retraining the model. The signal is that sparse expert routing is becoming a control surface, not just an efficiency trick. Collected because Aman has MoE experience and because routing interventions are unusually amenable to small mechanistic probes.

Hugging Face Daily Papers — Talker-T2AV: Joint Talking Audio-Video Generation with Autoregressive Diffusion Modeling

Link: https://huggingface.co/papers/2604.23586

Summary: Presents talking audio-video generation with shared high-level cross-modal modeling and modality-specific low-level decoders. The mechanism is explicit separation of semantic coupling from low-level audio/visual rendering details. Collected because it is directly relevant to speech/talking-face systems and to probing where audio and facial-motion representations should couple or decouple.

GitHub Releases — MLX v0.31.2

Link: https://github.com/ml-explore/mlx/releases/tag/v0.31.2

Summary: MLX added wider CUDA quantized matmul support, independent multi-threaded computations, CUDA FFT, and JACCL as a standalone library. This is mostly infrastructure, but it changes local experiment economics and makes more quantization/distributed prototypes cheap. Collected as an on-device/local-compute signal rather than a model-release signal.

GitHub Releases — vLLM v0.20.1

Link: https://github.com/vllm-project/vllm/releases/tag/v0.20.1

Summary: vLLM’s release focuses on DeepSeek V4 stabilization and performance work: multi-stream pre-attention GEMM, BF16/MXFP8 communication support, FP4 conversion improvements, optimized head computation, and MoE/top-k fixes. The signal is that serving kernels are now deeply architecture-specific. Collected because inference optimizations can become controlled perturbations for mechanism experiments.

GitHub Releases — SGLang v0.5.10

Link: https://github.com/sgl-project/sglang/releases/tag/v0.5.10

Summary: SGLang enabled piecewise CUDA graph capture by default, added elastic expert-parallel failure tolerance for MoE serving, GPU staging buffers for disaggregated prefill/decode, and sparse-attention integration. This is a strong systems signal around complex-control-flow serving. Collected because it suggests measuring not only throughput, but how serving layout choices affect model behavior under long context or MoE routing.

GitHub Releases — Transformers v5.7.0

Link: https://github.com/huggingface/transformers/releases/tag/v5.7.0

Summary: Transformers added Laguna, an MoE architecture with per-layer head counts sharing the same KV-cache shape and a sigmoid MoE router with auxiliary-loss-free load balancing. The release is model-support infrastructure, but the mechanism is routing/load balancing design. Collected as supporting evidence for MoE routing and KV-cache-shape as architecture control surfaces.

Apple ML Research — Reinforced Agent: Inference-Time Feedback for Tool-Calling Agents

Link: https://machinelearning.apple.com/research/reinforced-agent-inference-feedback

Summary: Moves agent evaluation into the active execution loop by using a specialized reviewer agent to provide inference-time feedback for tool-calling. The signal is real-time correction rather than post-hoc trajectory grading. Collected because it links agent memory/tool use to RL-style feedback without requiring full retraining.

Apple ML Research — STARFlow-V: End-to-End Video Generative Modeling with Normalizing Flows

Link: https://machinelearning.apple.com/research/starflow-v-video-modeling

Summary: Revisits normalizing flows for video generation, emphasizing end-to-end learning, causal prediction, and native likelihood estimation as alternatives to diffusion-only video pipelines. The signal is a renewed likelihood-based generative path for sequential visual data. Collected as a mechanism/theory-adjacent counterpoint to diffusion dominance.
