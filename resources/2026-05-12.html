AI Research Scout Resources — 2026-05-12

Core DL/LLM research

arXiv — Fast Byte Latent Transformer

Type: Paper

Link: https://arxiv.org/abs/2605.08044v1

Summary: A new BLT variant attacks byte-level generation speed with block-wise diffusion, self-speculation, and diffusion-plus-verification. It was collected because byte-level LMs remove tokenizer brittleness but usually pay a byte-by-byte decoding tax. The mechanism signal is parallel byte generation plus verification as a way to keep tokenizer-free modeling while cutting memory-bandwidth cost.

Personalization: medium

arXiv — STARFlow2: Bridging Language Models and Normalizing Flows for Unified Multimodal Generation

Type: Paper

Link: https://arxiv.org/abs/2605.08029v1

Summary: STARFlow2 argues that autoregressive normalizing flows are structurally closer to LLM decoding than diffusion image generators because they share causal masks, left-to-right generation, and KV-cache mechanics. It interleaves a VLM stream and a TarFlow stream so visual outputs can enter the cache without re-encoding. Collected as a clean architecture signal for cache-friendly unified multimodal generation.

Personalization: low

arXiv — GazeVLM: Active Vision via Internal Attention Control for Multimodal Reasoning

Type: Paper

Link: https://arxiv.org/abs/2605.07817v1

Summary: GazeVLM adds learned gaze tokens that modulate a causal attention mask, letting the model suppress irrelevant visual features and focus locally without external crop tools or extra visual-token floods. The GRPO-trained policy rewards valid grounding. Collected because it turns visual attention allocation into an internal controllable mechanism rather than a separate agent wrapper.

Personalization: low

HF Papers — LLMs Improving LLMs: Agentic Discovery for Test-Time Scaling

Type: Paper

Link: https://huggingface.co/papers/2605.08083

Summary: AutoTTS searches over width-depth test-time-scaling controllers using pre-collected trajectories and cheap probe signals instead of repeated expensive LLM calls. It is useful because the learned object is not an answer but a compute-allocation policy: branch, continue, probe, prune, or stop. The mechanism is controller synthesis over inference traces.

Personalization: medium

arXiv — DiffRetriever: Parallel Representative Tokens for Retrieval with Diffusion Language Models

Type: Paper

Link: https://arxiv.org/abs/2605.07210v1

Summary: DiffRetriever uses diffusion language models to read multiple masked representative positions in one bidirectional pass, avoiding autoregressive latency for multi-representative retrieval. It was collected because it shows a concrete capability difference between AR and diffusion LMs: parallel representative-token extraction. The learning value is retrieval as a place where diffusion-style parallelism may be structurally useful, not only generative.

Personalization: low

Training/RL/math/mech interp

arXiv — Beyond Pairs: Your Language Model is Secretly Optimizing a Preference Graph

Type: Paper

Link: https://arxiv.org/abs/2605.08037v1

Summary: GraphDPO generalizes pairwise DPO to directed acyclic preference graphs induced by multiple ranked rollouts per prompt. It preserves transitivity, handles equivalence layers, and keeps per-prompt complexity linear via log-sum-exp aggregation. Collected because it treats alignment data as a graph-structured supervision object rather than independent pairs.

Personalization: medium

HF Papers — Rethinking RL for LLM Reasoning: It’s Sparse Policy Selection, Not Capability Learning

Type: Paper

Link: https://huggingface.co/papers/2605.06241

Summary: This paper claims RL reasoning gains concentrate at only 1–3% of high-entropy token positions, promoting tokens already in the base model’s top-5 alternatives. ReasonMaxxer then applies contrastive loss only at entropy-gated decision points and reportedly matches RL with far less compute. Collected as a strong sparse-control hypothesis: RL may mostly select latent branches rather than teach new algorithms.

Personalization: medium

HF Papers — Listwise Policy Optimization: Group-based RLVR as Target-Projection on the LLM Response Simplex

Type: Paper

Link: https://huggingface.co/papers/2605.06139

Summary: LPO reframes group-based RLVR as defining a target distribution on the response simplex and projecting the policy toward it by exact divergence minimization. It was collected because it gives a geometric language for GRPO-like updates: what target distribution is being implied by a group’s advantages? The mechanism signal is stable listwise projection with response diversity preservation.

Personalization: medium

arXiv — KL for a KL: On-Policy Distillation with Control Variate Baseline

Type: Paper

Link: https://arxiv.org/abs/2605.07865v1

Summary: vOPD casts on-policy distillation as policy-gradient RL and introduces a closed-form value baseline equal to per-token negative reverse KL between student and teacher. It aims to reduce variance without adding a critic or full-vocabulary overhead. Collected because OPD is becoming a recurring post-training primitive and this paper isolates a variance-reduction mechanism.

Personalization: medium

HF Papers — Mean Mode Screaming: Mean–Variance Split Residuals for 1000-Layer Diffusion Transformers

Type: Paper

Link: https://huggingface.co/papers/2605.06169

Summary: This mechanistic training paper describes collapse in very deep DiTs where residual streams become mean-dominated and centered variation is suppressed. MV-Split residuals separately handle centered updates and trunk-mean replacement to stabilize 400–1000 layer DiTs. Collected because it is a rare architecture-training dynamics signal at extreme depth, with a concrete residual-stream failure mode.

Personalization: low

arXiv — Layer Collapse in Diffusion Language Models

Type: Mech interp

Link: https://arxiv.org/abs/2605.06366v1

Summary: This paper finds that early layers of LLaDA-like diffusion language models collapse into redundant activation patterns dominated by a persistent super-outlier, yet that outlier is causally important. It also reports compression behavior opposite to autoregressive LMs, including stronger robustness to low-bit quantization. Collected because DLMs may have different layer dynamics and deployment rules than AR models.

Personalization: medium

OpenReview — Decomposing LLM Computation with Jets

Type: Math/theory

Link: https://openreview.net/forum?id=u6JLh0BO5h

Summary: Jets are proposed as a way to decompose LLM computations into explicit input-output path contributions plus remainders. This is not yet a plug-and-play tool, but it gives a formal vocabulary for disentangling computations that SAEs and patching only approximate empirically. Collected as a broad learning item for mechanistic decomposition.

Personalization: low

Audio/TTS/speech

arXiv — PairAlign: Sequence Tokenization via Self-Alignment with Applications to Audio Tokenization

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.06582v1

Summary: PairAlign treats audio tokenization as conditional sequence generation and trains content-preserving views to predict each other’s token sequences while unrelated sequences act as competitors. It optimizes sequence consistency, compactness, length, EOS placement, and edit-like stability rather than just local codec reconstruction. Collected because speech-token interfaces are central to audio memory and reasoning.

Personalization: medium

arXiv — MiniMind-O Technical Report: An Open Small-Scale Speech-Native Omni Model

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.03937v1

Summary: MiniMind-O is a 0.1B-scale open omni model with text, speech, image inputs and text/streaming-speech outputs. Its Thinker/Talker split, Mimi-code buffer, speaker token, and released multimodal sequence format make the full loop inspectable. Collected because small speech-native systems are cheap enough for factor and codec-interface probes.

Personalization: high

arXiv — TextPro-SLM: Your Speech LLM Can Be a Prosody-Aware Text LLM

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.05927v2

Summary: TextPro-SLM reduces the speech/text modality gap from the input side by pairing synchronized text tokens with prosody embeddings before the LLM. It reports strong paralinguistic understanding with roughly 1,000 hours of LLM training audio. The mechanism is factorized input representation: text-like semantics plus prosody channels instead of one overloaded speech latent.

Personalization: medium

arXiv — X-Voice: Zero-Shot Cross-Lingual Voice Cloning

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.05611v1

Summary: X-Voice is a 0.4B multilingual zero-shot voice cloning model trained over 30 languages with IPA as a shared representation and a two-stage prompt-text-masking recipe. It extends F5-TTS with language-ID injection and classifier-free guidance scheduling. Collected because it exposes concrete levers for cross-lingual speaker transfer: phonemic representation, prompt transcript removal, and language conditioning.

Personalization: low

arXiv — Task-Aware Answer Preservation under Audio Compression for Large Audio Language Models

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.06631v1

Summary: This paper evaluates audio compression by downstream LALM answer preservation, especially the worst-affected query families, rather than aggregate codec quality. It proposes a statistical sign-off protocol for compression budgets. Collected as a failure-slice guardrail: compression can look acceptable on average while damaging one deployment-critical question family.

Personalization: medium

arXiv — Star Elastic: Many-in-One Reasoning LLMs with Efficient Budget Control

Type: Paper

Link: https://arxiv.org/abs/2605.07182v1

Summary: Star Elastic post-trains nested submodels inside a parent reasoning model across SSM, embedding, MoE, and FFN axes, then routes different submodels by reasoning phase. It also extends to FP8/NVFP4 quantized elastic checkpoints. Collected because it makes model size and precision an inference-time control variable rather than a fixed deployment choice.

Collected because long-context experimentation often dies on plumbing before modeling starts. The mechanism/tooling signal is compiler/runtime transformation of ordinary model code into distributed sequence parallelism.

Personalization: medium

PyTorch Blog — In-Kernel Broadcast Optimization: Co-Designing Kernels for RecSys Inference

Type: Infra/GPU

Link: https://pytorch.org/blog/in-kernel-broadcast-optimization-co-designing-kernels-for-recsys-inference/

Summary: IKBO eliminates explicit replication of shared user embeddings/sequences by fusing broadcast logic into GPU kernels. Although the example is RecSys, the learning value generalizes to ML inference: when model structure repeats inputs across candidates, kernel-level broadcast can remove a memory movement bottleneck. Collected as a kernel-model co-design pattern.

arXiv — Beyond Confidence: Rethinking Self-Assessments for Performance Prediction in LLMs

Type: Paper

Link: https://arxiv.org/abs/2605.07806v1

Summary: This paper finds that verbalized confidence is an inconsistent and overoptimistic correctness predictor, while appraisal dimensions such as effort and ability can perform better depending on task type. Collected as a skeptical deployment signal: asking a model “are you confident?” is too coarse. The mechanism value is multidimensional self-assessment tied to task characteristics.

arXiv — Asymmetric Phase Coding Audio Watermarking

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.07241v1

Summary: APC is a training-free cryptographic signing layer for audio using Ed25519 signatures, Reed-Solomon coding, STFT phase-bin selection, and QIM over log-magnitude differences. It is a skeptical/provenance signal because passive deepfake detectors are brittle and utterance-level classifiers can miss partial manipulation. The mechanism is auditable signing rather than learned authenticity judgment.
