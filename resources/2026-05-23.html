arXiv — Vector Policy Optimization: Training for Diversity Improves Test-Time Search

Type: Paper

Link: https://arxiv.org/abs/2605.22817v1

Summary: A reasoning-RL paper arguing that standard likelihood-style updates can under-prepare models for inference-time search, where many diverse rollouts are sampled and filtered by task rewards. The mechanism signal is explicit diversity training: optimize a vector-valued policy objective so the rollout set has more useful behavioral spread, not merely higher average correctness. Collected because it connects post-training objectives to test-time compute/search behavior.

Personalization: medium

arXiv — Two is better than one: A Collapse-free Multi-Reward RLIF Training Framework

Type: Paper

Link: https://arxiv.org/abs/2605.22620v1

Summary: Proposes a reinforcement-learning-from-internal-feedback setup with multiple reward signals to reduce collapse in reasoning post-training. The useful mechanism is reward-channel diversification: internal evaluators can provide a training signal, but single-channel reward can compress behavior, so multi-reward structure becomes a stability control. It is relevant to RLVR/GRPO-style questions without being only a benchmark result.

Personalization: medium

Hugging Face Papers — DelTA: Discriminative Token Credit Assignment for Reinforcement Learning from Verifiable Rewards

Type: Paper

Link: https://huggingface.co/papers/2605.21467

Summary: DelTA targets the response-level-to-token-level credit-assignment gap in RLVR. It treats the hard part as identifying which tokens or spans caused verifiable success, rather than spreading outcome reward uniformly over the whole trace. Collected because token credit maps are becoming a repeated mechanism in reasoning-model training.

Personalization: medium

arXiv — Clipping Bottleneck: Stabilizing RLVR via Stochastic Recovery of Near-Boundary Signals

Type: Paper

Link: https://arxiv.org/abs/2605.22703v1

Summary: Studies instability in RLVR through the lens of clipped policy-gradient updates and near-boundary signals that may be discarded or distorted. The core mechanism is optimizer geometry: clipping can protect against large destructive updates while also hiding useful weak advantages. This is a good skeptical/diagnostic companion to new RLVR methods.

Personalization: medium

arXiv — Search-E1: Self-Distillation Drives Self-Evolution in Search-Augmented Reasoning

Type: Paper

Link: https://arxiv.org/abs/2605.22511v1

Summary: Presents a search-augmented reasoning recipe where self-distillation helps a model improve with less elaborate external machinery. The mechanism signal is a feedback loop between retrieval/search traces, generated reasoning, and distilled training data. It is useful for understanding when self-generated traces are improvement signals versus stale self-imitation.

arXiv — Unified Data Selection for LLM Reasoning

Type: Paper

Link: https://arxiv.org/abs/2605.22389v1

Summary: Addresses the bottleneck of selecting high-value reasoning data for long-CoT training. The collected mechanism is data selection as gradient routing: the model's reasoning ability depends not only on total data volume but on which examples expose useful intermediate structure and failure boundaries. Useful broad learning item for post-training/data-mixture design.

Personalization: low

arXiv — Tokenisation via Convex Relaxations

Type: Math/theory

Link: https://arxiv.org/abs/2605.22821v1

Summary: Reframes tokenization away from greedy BPE/Unigram choices and toward a convex-relaxation view of vocabulary construction. The mechanism value is mathematical: tokenization can be studied as a global optimization problem rather than a sequence of local merges. Collected as a broad foundation item because tokenizer decisions affect frequency skew, rare-token learning, and downstream representation geometry.

Personalization: low

Hugging Face Papers — Full Attention Strikes Back: Transferring Full Attention into Sparse within Hundred Training Steps

Type: Paper

Link: https://huggingface.co/papers/2605.16928

Summary: A long-context efficiency paper about transferring a full-attention model into a sparse-attention regime with very little additional training. The mechanism signal is attention-pattern transfer: instead of training sparse attention from scratch or using heuristic eviction, distill/convert a dense attention behavior into a cheaper structure. Collected for long-context inference and rare-evidence retention questions.

Personalization: medium

arXiv — LCGuard: Latent Communication Guard for Safe KV Sharing in Multi-Agent Systems

Type: Paper

Link: https://arxiv.org/abs/2605.22786v1

Summary: Examines safety for latent communication and KV sharing in multi-agent LLM systems. The mechanism is not generic agent safety; it is that sharing hidden state/KV can leak or transmit information outside natural-language observability. Useful as a skeptical signal for any agent architecture that treats latent state exchange as a cheap coordination primitive.

Personalization: medium

arXiv — RobustSpeechFlow: Learning Robust Text-to-Speech Trajectories via Augmentation-based Contrastive Flow Matching

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.22083v1

Summary: Focuses on skip/repeat/content-fidelity failures in flow-matching TTS and introduces augmentation-based contrastive flow matching to improve trajectories. The mechanism is trajectory robustness: the model should learn flow paths that preserve content under alignment noise and perturbations. Important for TTS because naturalness alone can hide content errors.

arXiv — Automatic Contextual Audio Denoising

Type: Audio/TTS

Link: https://arxiv.org/abs/2605.22262v1

arXiv — Runtime-Certified Bounded-Error Quantized Attention

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.20868v1

Summary: Proposes runtime certification for bounded-error quantized attention, especially relevant to low-memory KV-cache and long-context inference. The mechanism is a sign-off layer: instead of trusting average empirical robustness, the runtime detects or bounds approximation error. Collected because quantized attention is becoming a causal transformation in deployed LLM behavior.

arXiv — OCTOPUS: Optimized KV Cache for Transformers via Octahedral Parametrization Under optimal Squared error quantization

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.21226v1

Summary: A KV-cache compression paper using structured parametrization and quantization to reduce long-context inference memory. The mechanism signal is geometry-aware cache coding: rotate/parameterize KV states so quantization error is better controlled. This matters because cache compression can preserve or erase rare evidence differently from weight quantization.
