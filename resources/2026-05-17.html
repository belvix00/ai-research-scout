arXiv — Learning from Language Feedback via Variational Policy Distillation

Type: Paper

Link: https://arxiv.org/abs/2605.15113v1

Summary: Core bucket: Training/RL/math/mech interp. This paper targets a concrete weakness in RLVR: sparse outcome rewards do not tell a reasoning model which intermediate moves were useful. It proposes a variational policy distillation loop where language feedback becomes denser supervision, while the teacher evolves instead of remaining a fixed stale target. Collected because it is a mechanism-level signal about credit-channel width in reasoning RL, not just another benchmark result.

Personalization: medium

arXiv — Self-Distilled Agentic Reinforcement Learning

Type: Paper

Link: https://arxiv.org/abs/2605.15155v1

Summary: Core bucket: Training/RL/math/mech interp. The paper studies long-horizon LLM agents where trajectory-level reward is too coarse, and uses on-policy self-distillation to convert successful behavior into finer guidance. The mechanism signal is dense supervision inside the rollout lifecycle: which steps get copied, which failure steps remain invisible, and whether the distillation target follows the current policy distribution. This is useful for understanding why agent RL often depends as much on trajectory plumbing as on the named optimizer.

Personalization: medium

arXiv — When Are Two Networks the Same? Tensor Similarity for Mechanistic Interpretability

Type: Mech interp

Link: https://arxiv.org/abs/2605.15183v1

Summary: Core bucket: Training/RL/math/mech interp. This paper asks how to compare whether parts of two networks implement the same computation, beyond behavioral similarity or simple representation metrics. It is useful because reproducibility and modular interpretability need a notion of computational equivalence before claims about circuits can transfer across models. The mechanism signal is tensor-level similarity as an audit primitive for circuits, subnetworks, and intervention transfer.

arXiv — Forgetting That Sticks: Quantization-Permanent Unlearning via Circuit Attribution

Type: Paper

Link: https://arxiv.org/abs/2605.15138v1

Summary: Core bucket: Skeptical or failure signal. The paper argues that normal unlearning tests can be misleading because deployed language models are usually quantized after training. It uses circuit attribution to make forgetting survive 4-bit post-training quantization, reinforcing that deployment compression is a causal transformation, not a passive packaging step. Collected as a skeptical signal for any editing, refusal, unlearning, or steering claim evaluated only in full precision.

Personalization: high

arXiv — Widening the Gap: Exploiting LLM Quantization via Outlier Injection

Type: Paper

Link: https://arxiv.org/abs/2605.15152v1

Summary: Core bucket: Skeptical or failure signal. This work studies an attack where a model can look benign in full precision but behave differently after quantization because outlier structure changes the low-bit representation. The mechanism is deployment aliasing: small or hidden weight-space features can be amplified or remapped by quantization bins. It pairs well with quantization-permanent unlearning as evidence that low-bit paths need their own safety and mechanism audits.

Personalization: high

arXiv — XFP: Quality-Targeted Adaptive Codebook Quantization with Sparse Outlier Separation for LLM Inference

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.14844v1

Summary: Core bucket: Inference/ML infra/GPU. XFP inverts the usual quantization workflow by letting the operator specify reconstruction-quality floors, then adapting codebooks and separating sparse outliers. The useful mechanism is per-channel quality targeting rather than a fixed bit-width recipe, which is relevant for preserving fragile attention or MLP channels. It is a systems item with direct implications for mechanism-preserving inference experiments.

arXiv — A Hardware-Aware, Per-Layer Methodology for Post-Training Quantization of Large Language Models

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.14929v1

Summary: Core bucket: Inference/ML infra/GPU. The paper presents Scaled Outer Product post-training quantization for near-lossless 4.5–6 bit LLM weights under hardware constraints with per-layer LUT decode. The mechanism signal is that different layers may need different compression structures if the deployment target is real hardware rather than an abstract quantizer. This broadens the quantization discussion from accuracy retention to hardware-specific representational distortion.

arXiv — KVServe: Service-Aware KV Cache Compression for Communication-Efficient Disaggregated LLM Serving

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.13734v1

Summary: Core bucket: Inference/ML infra/GPU. Disaggregated prefill/decode serving makes KV movement a communication bottleneck; KVServe compresses KV state with service awareness. It is useful because long-context and agent runs increasingly depend on KV state as the actual memory interface.

arXiv — An Interpretable Latency Model for Speculative Decoding in LLM Serving

Type: Infra/GPU

Link: https://arxiv.org/abs/2605.15051v1

Summary: Core bucket: Inference/ML infra/GPU.
