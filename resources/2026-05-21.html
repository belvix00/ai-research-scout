Core DL/LLM research

Hugging Face Papers / arXiv — RoPE Distinguishes Neither Positions Nor Tokens in Long Contexts, Provably

Type: Paper

Link: https://arxiv.org/abs/2605.15514

Summary: A theoretical long-context paper arguing that RoPE has intrinsic non-identifiability: the embedding transform alone does not uniquely distinguish positions or tokens once the analysis abstracts away from implementation details. It is useful because it turns a familiar positional encoding into a concrete failure mechanism for long-context extrapolation and rare-evidence retrieval, not just an empirical quirk. The mechanism signal is positional aliasing under rotary geometry.

Personalization: medium

Hugging Face Papers / arXiv — Stage-adaptive Token Selection for Efficient Omni-modal LLMs

Type: Paper

Link: https://arxiv.org/abs/2605.20035

Summary: Omni-modal LLMs interleave audio and video token streams, making token count the central bottleneck. This paper proposes selecting tokens adaptively by processing stage, which is a direct mechanism for deciding which perceptual evidence survives into language reasoning. It belongs in the scout because adaptive token dropping can either make multimodal models cheap or silently erase rare acoustic/visual cues.

Personalization: medium

Training/RL/math/mech interp

Hugging Face Papers / arXiv — Anti-Self-Distillation for Reasoning RL via Pointwise Mutual Information

Type: Paper

Link: https://arxiv.org/abs/2605.11609

Summary: A reasoning-RL paper that explicitly questions naive self-distillation: if the model copies its own high-probability traces, it may reinforce common but uninformative behavior. The pointwise-mutual-information framing suggests a way to reward information-bearing reasoning moves rather than popularity under the current policy. This is a strong signal for studying RLVR as distribution shaping over branches.
