arXiv — UniPool: A Globally Shared Expert Pool for Mixture-of-Experts

Type: Paper

Link: https://arxiv.org/abs/2605.06665v1

Bucket: Core DL/LLM research

Summary: UniPool questions the default MoE assumption that every transformer layer should own a private expert set. The useful mechanism signal is expert capacity as a globally shared pool, which turns routing into a cross-layer allocation problem rather than a layer-local sparse-compute trick. Collected because it gives concrete probes for expert reuse, layer specialization, rare-feature retention, and parameter growth under matched active compute.
